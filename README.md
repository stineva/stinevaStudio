# Local AI Studio

استودیوی محلی برای تولید و تکامل پروژه‌های فرانت‌اند Next.js با مدل‌های محلی Ollama.

## پیش‌نیازها

- Node.js 18+
- npm
- Git
- Ollama (با مدل دانلود شده)

## نصب

```bash
npm install
```

## اجرای محیط توسعه

```bash
npm run dev
```

## ساخت نسخه نهایی

```bash
npm run build
```

## اجرای lint

```bash
npm run lint
```

## نحوه کار Pipeline

1. دریافت پرامپت کاربر و ساخت برنامه (PLAN) به صورت JSON.
2. تولید پچ unified diff بر اساس برنامه.
3. اعمال پچ در پروژه هدف با `git apply`.
4. اجرای اعتبارسنجی (`npm run lint` و `npm run build`).
5. در صورت خطا، ارسال لاگ‌ها به مدل و دریافت پچ اصلاحی.
6. ثبت اجرای کامل در پایگاه داده و ذخیره هر پچ به عنوان یک commit.

## قالب‌ها

قالب‌های پیش‌فرض در پوشه `templates/` قرار دارند. برای افزودن قالب جدید:

1. یک پوشه جدید در `templates/` بسازید.
2. ساختار Next.js App Router با Tailwind و فایل‌های `SPEC.md`, `CONVENTIONS.md`, `ARCHITECTURE.md` را اضافه کنید.
3. مسیر قالب را در بخش ساخت پروژه به دلخواه استفاده کنید.

## نکات امنیتی

- اجرای دستورات فقط به لیست سفید محدود است: `npm install`, `npm run lint`, `npm run build`, `npm run dev`.
- تمامی عملیات فایل محدود به پوشه پروژه انتخابی است.
